#  Space Exploration Web Game

A browser-based interactive **Space Exploration Simulation Game** developed using **HTML5, CSS3, and JavaScript**.

This project allows players to control a spaceship, explore planets, manage resources, and complete missions while surviving random space events.

---

##  Features

*  Spaceship control dashboard
*  Planet exploration system
*  Resource management (Fuel, Oxygen, Hull)
*  Random space events (asteroids, aliens, treasure)
*  Mission progression system
*  Upgrade system for spaceship components
*  Achievements and leaderboard
*  Progress saving using LocalStorage
*  Futuristic space-themed UI with animations

---

## Technologies Used

* **HTML5** – webpage structure
* **CSS3** – futuristic UI styling and animations
* **JavaScript (ES6)** – game logic and interactivity

---

## 📂 Project Structure

```
Space-Exploration-Web-Game
│
├── index.html     # Main game interface
├── style.css      # Game styling and animations
└── script.js      # Game logic and mechanics
```

---

##  Gameplay Overview

1. Start a mission from the launch screen.
2. Travel between planets in the solar system.
3. Manage spaceship resources like fuel and oxygen.
4. Survive random space events.
5. Earn points and unlock upgrades.
6. Complete missions and explore new galaxies.
